# 🌱 AgriVision

AgriVision is a modern, responsive web application built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.  
It aims to streamline agricultural processes and provide a seamless digital interface for farming and agri-related data visualization.

---

## 🚀 Live Demo

🔗 [https://astha-arya.github.io/AgriVision](https://astha-arya.github.io/AgriVision)

---

## 🛠️ Tech Stack

- ⚛️ **React** – Frontend framework
- 🌀 **Vite** – Super-fast bundler and dev server
- 💅 **Tailwind CSS** – Utility-first CSS for styling
- 🔠 **TypeScript** – Type-safe JavaScript
- 🌍 **GitHub Pages** – Deployment platform
