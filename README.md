# AgriVision 🌾

AgriVision is a modern, responsive web application built using **Vite**, **React**, **TypeScript**, and **Tailwind CSS**.

## 🚀 Features

- 📱 Responsive design
- 🌐 Fast development with Vite
- 💅 Styled using Tailwind CSS
- ⚙️ Built with TypeScript for better maintainability

## 🛠️ Tech Stack

- [Vite]
- [React]
- [TypeScript]
- [Tailwind CSS]
